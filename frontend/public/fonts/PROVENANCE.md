# Recovered local font baseline

These seven unchanged WOFF2 subsets were recovered from existing local compiled
output. This is a NEW audited byte baseline, not proof of equality to historical
artifacts lost in an environment reset. Embedded names identify Instrument Sans
1.000, Bricolage Grotesque 1.001, and Spline Sans Mono 1.004. This is not vendor
attestation or proof of the historical download chain. No font was downloaded,
modified, re-subsetted, or converted for this migration.

The embedded 2022 family copyright notices and OFL references are corroborated by
the official upstream license text below (read 2026-10-23). Complete family notices
are bundled alongside the fonts. Retain them in source, Docker images, and any
redistribution; font software remains under SIL OFL 1.1. No endorsement implied.
License text was captured from the web tool's complete numbered text, normalized
to UTF-8/LF with a final newline; hashes identify these bundled notice bytes, not
an asserted byte-for-byte HTTP response or historical versioned release.
