# Public portable-project example

`public-fixture-project.zip` is generated by the isolated native SurrealDB/SQLite
roundtrip test. It contains only developer-authored public fixture text:
“真实原件与历史引用。” (real originals and historical citations), a simple note,
one synthetic V1 answer, and two synthetic visible chat messages.

The source extraction and export/restore are real CPU/database/file operations.
The answer and chat messages are deliberately constructed test data; no Google
account or model service was called. They are not evidence of real model quality.

Use the workbench's portable import control to create a new notebook. The
archive includes an original TXT, extraction, evidence, native note, citation
snapshot, and normalized SQLite history. On restore the historical citation
remains readable but is marked unverified. No credentials, connection profile,
internal execution checkpoints, embedding vectors, or private user content are
included. The archive's SHA-256 is recorded below.

SHA-256: `974f773c85ec771badd109d3a65da8a76163d9c460f3eeaaffb1258a89acbd31`

`browser-fixture-project.zip` is a richer public fixture exported through the real Firefox UI and imported through the same UI into a new notebook. It contains the Chinese PDF/MD/TXT originals, known-reference notes and browser-authored note; malformed/image-only examples are intentionally included with honest failed/needs_ocr states. No actual model answer or Google account data is included. The ZIP was validated before source packaging. See `../evidence/browser/` for ten exact citation checks and Chinese screenshots.
